# Ingos kleine Kältehilfe - Website

Eine professionelle Website für die Kältehilfe-Initiative "Ingos kleine Kältehilfe - Hand in Hand e.V." aus Saarbrücken.

## 🌟 Features

- **Responsive Design**: Funktioniert auf allen Geräten (Desktop, Tablet, Mobile)
- **Vollständig in Deutsch**: Alle Inhalte wurden ins Deutsche übersetzt
- **Echte Daten**: Basiert auf den tatsächlichen Informationen der Kältehilfe
- **Social Media Integration**: Links zu Facebook und Instagram
- **Spendenformular**: Mit echten PayPal-Daten (hand-in-hand@gmx.de)
- **Kontaktinformationen**: Aktuelle Adresse und Telefonnummer
- **Sauberer Code**: HTML5, CSS3, Bootstrap 5

## 📁 Dateistruktur

```
k-hilfe/
├── index.html          # Hauptseite
├── donate.html         # Spendenseite
├── news.html          # Neuigkeiten (Vorlage)
├── news-detail.html   # Artikel Details (Vorlage)
├── css/               # Stylesheets
├── js/                # JavaScript Dateien
├── images/            # Bilder und Logo
├── fonts/             # Schriftarten
└── README.md          # Diese Datei
```

## 🚀 Installation & Deployment

### Option 1: Einfacher Upload (Empfohlen)
1. Alle Dateien aus dem `k-hilfe/` Ordner herunterladen
2. Auf den Webserver hochladen (z.B. via FTP bei IONOS)
3. Sicherstellen, dass `index.html` als Startseite eingestellt ist

### Option 2: Lokale Entwicklung
```bash
# Repository klonen
git clone [REPOSITORY_URL]
cd k-ltehilfe_website/k-hilfe

# Lokalen Server starten (Python)
python3 -m http.server 8000

# Im Browser öffnen: http://localhost:8000
```
