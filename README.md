# k-ltehilfe_webseite

Dieses Repository enthält eine einfache statische Webseite für **Ingos kleine Kältehilfe – Hand in Hand e.V.**

## Ordnerstruktur

- `template/` – ursprüngliches Template (unverändert).
- `k-hilfe/` – angepasste Version für die Kältehilfe mit Mehrsprachigkeit.

## Nutzung

Die Seiten unter `k-hilfe/` können direkt auf einen Webserver kopiert werden.

## Entwicklung

Es werden keine Build-Tools benötigt. Änderungen an HTML, CSS oder JavaScript können direkt vorgenommen werden.

## Lizenz

Das verwendete Template stammt von [TemplateMo](https://templatemo.com) und ist kostenlos nutzbar.
