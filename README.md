# Kältehilfe Website

Einfache statische Website für die Kältehilfe-Initiative.

## Aufbau
- `index.html` – Startseite
- `impressum.html` – rechtliche Angaben
- `datenschutz.html` – Datenschutzerklärung
- `style.css` – Gestaltung
- `concept.md` – Konzept und Plan

## Lokale Vorschau
Starte einen lokalen Server und rufe die Seite im Browser auf:
```bash
python3 -m http.server
```

## Deployment
Alle HTML- und CSS-Dateien können per FTP oder Dateimanager auf einen beliebigen Hoster (z. B. IONOS) hochgeladen werden. Es ist keine weitere Konfiguration erforderlich.
