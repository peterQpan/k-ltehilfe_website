## Wofür wir da sind

In Saarbrücken unterstützt Ingos kleine Kältehilfe obdachlose Menschen und andere Menschen in Not. Dazu gehören warme Mahlzeiten ein bisschen Zeit fürGespräche. Auf unserer Website erzählen wir von der Arbeit vor Ort und zeigen, wie du sie unterstützen kannst.

## An der Website mitarbeiten

Dieses Repository enthält die Website des Vereins. [Hugo](https://gohugo.io/) setzt die Texte und Seitenvorlagen zu einer statischen Website zusammen.

| Was möchtest du tun? | Hier findest du den Einstieg |
| --- | --- |
| Eine Neuigkeit veröffentlichen | [Beiträge unter `content/aktuelles/`](content/aktuelles/) |
| Eine Seite überarbeiten | [Seiteninhalte unter `content/`](content/) und [Vorlagen unter `layouts/`](layouts/) |
| Bilder oder das Vereinsicon finden | [Bildersammlung unter `static/images/`](static/images/) |
| Farben und Abstände anpassen | [Stylesheets unter `static/css/`](static/css/) |
| Seitentitel oder Beschreibung ändern | [Website-Konfiguration in `hugo.toml`](hugo.toml) |

### Änderungen lokal ansehen

Wenn Hugo installiert ist, starte die Vorschau im Hauptverzeichnis des Projekts.

```sh
hugo server
```

Öffne die im Terminal angezeigte lokale Adresse. Während du Texte oder Vorlagen bearbeitest, aktualisiert Hugo die Vorschau.
